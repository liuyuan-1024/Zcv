# 组合文档滚动：Zed 对齐与验证

验证日期：2026-09-29。场景对应暂存、未暂存组合文档在 release 构建、启用自动换行时的延迟、跳动与滚动不跟手。

## 架构边界

以本机 Zed `bd747337` 为对应实现依据，保留本地编辑器的所有权、快照与增量契约。Zcv 使用固定版本 GPUI `7cda6f0523f008aa4b3b4be700a6660923f9283c` 的 `LineWrapper` API；两者 API 参数有版本差异，但换行器由任务借用、取消后归还的生命周期一致。不引入协作、远程或 LSP。

| 本次滚动链路的差距 | 当前实现与所有者 | 对应 Zed 契约 |
| --- | --- | --- |
| 换行对整行塑形，并逐字符查询整行布局 | `WrapMap` 任务借用 GPUI `LineWrapper`，顺序消费文本与实测行内元素；仅可见布局进行塑形 | `editor/display_map/wrap_map.rs` 的重排任务与 `update_transforms` |
| 关闭换行后将局部编辑扩为整份显示失效 | `TabEdit` 转为局部 `WrapEdit`；跨行与断点变化即使总行数相同也发布几何变化 | 各层接收旧／新坐标 patch，向上输出本层 patch |
| 块同步维护全量规格，身份依赖 excerpt 序号 | `BlockSnapshot` 从换行、窗口边界、文件折叠范围合成 patch；cursor 共享未变树，范围查询只物化受影响块；身份保存组合 Anchor | `editor/display_map/block_map.rs` 的局部同步与 `header_and_footer_blocks` |
| Anchor 解析扫描同路径窗口，删除侧位置与 working 分离 | excerpt 摘要保存末端源 Anchor，按路径、源身份、稳定 Anchor 定位；删除侧以 working hunk 起点为主位置，附带基线 Anchor | `multi_buffer` 的摘要查询和删除侧 Anchor 模型 |
| 滚动帧重复触发内容消费与宿主状态扫描 | `DisplayMap` 无新输入时复用快照；Editor 以已消费版本驱动搜索、装饰与滚动几何；工具栏订阅语义事件，展开状态读块摘要，dirty 读组合源摘要 | 同一 Editor 的内容投影与滚动状态分别由所属层维护 |
| 高亮命中线性调整缓存顺序，空结果不受预算约束 | 语言层持有按成本预算的 LRU；命中、提升顺序为常数时间；空结果参与淘汰 | `language_core/highlight_cache.rs` 的 `CostBudgetedLru` |

唯一内容管线保持为：

```text
Buffer → LanguageBuffer → MultiBuffer → Fold → Tab → Wrap → Block
                                                        ↓
                                           DisplayMap 持有显示快照
                                                        ↓
                             Editor 消费新版本 → EditorElement 可见布局
```

滚动由 Editor 更新稳定 Anchor 与像素余量，触发可见布局。每帧仍可从同一同步入口拉取待处理变化，但没有新版本时不重搜、不替换装饰、不发布内容事件、不重建块树。窗口宽度变化是显示配置变化；后台换行完成是新的派生结果，二者仍通过同一入口发布，不能被当作纯滚动跳过。

源内容更新先同步，再刷新 excerpt 窗口，避免把新版本范围应用到旧源快照。源文首 `Before` 与文尾 `After` 保持最小／最大边界；其他位置使用稳定插入身份。窗口增删、删除侧收起、空文件增长和文首文尾插入都经同一 Anchor 查询协议处理。

对应不变量：`M-*` 的组合权威与源映射，`D-7/D-8/D-10/D-12/D-14` 的键控查询、增量覆盖与异步生命周期，`E-1/E-4/E-7` 的唯一 Editor 与滚动 Anchor，`R-1/R-2/R-3` 的可见布局和可丢弃缓存。完整约束见 [编辑器架构](编辑器架构.md)。

## 已执行的定向验证

未运行全量测试。以下相关模块与过滤组均通过：

| 边界 | 回归范围 |
| --- | --- |
| 文本与 Anchor | 稳定插入顺序、文尾 Before、空文件最小／最大边界、前后插入、亲和性与版本错误 |
| 组合投影 | 10 项 Anchor 回归；源编辑、局部输出 patch、删除侧、窗口刷新、空文件边界、dirty 摘要和元数据变化 |
| 块与换行 | 6 项块同步、11 项换行任务回归；24 项软换行行为通过；覆盖相同行数的断点重分布、取消、配置替换和重复窗口变化 |
| Editor | 16 项滚动回归、22 项搜索回归、11 项装饰回归；no-op、元数据 Tab 更新、dirty 事件与保存 |
| 差异宿主 | 滚动不通知宿主、折叠通知宿主、部分暂存、hunk 源身份保持 |
| 缓存与释放 | 5 项高亮预算与替换回归；换行取消、关闭文档与滚动刷新任务释放 |

`cargo check --offline -p Zcv`、显示基准编译及相关六个 crate 的 `cargo clippy --lib -- -D warnings` 通过；修改的 Rust 文件通过格式检查，`git diff --check` 通过。第三方 `block 0.1.6` 仍有已有的未来兼容性提示。

三个关键行为已由回归直接验证：

1. 启用实际软换行的 10 文件／500 行夹具，经连续滚轮、大跳转和重绘，文本、元数据、显示版本均不变。
2. 批量折叠 10 个文件只提交一次显示变化、发布一次语义事件；相同策略重复设置不发布变化。
3. 文件移除后再取消其折叠，策略快照正确收敛；后续空帧不持续提交显示版本。

## release 测量

环境为本机 macOS 26.3.1，工作区版本 0.9.95，Cargo release 构建。GPUI 测试文本系统，不包含真实字体塑形、系统输入队列和 GPU 呈现，也未测量完整 DiffView 宿主帧。测量时串行运行，无并行构建。

### 后台任务收敛后的滚动

每文件 50 行变更，包含长行、中文与 Tab；暂存使用只读组合文档，未暂存使用可编辑组合文档，均为真实 diff 并展开删除侧。固定窗口宽度，先等待换行任务收敛，再测量 240 帧交替滚动。每轮同时断言显示版本不变。相同构建连续测量两轮：

| 场景 | 中位数，两轮（ms） | P95，两轮（ms） | 两轮样本范围（ms） |
| --- | --- | --- | --- |
| 暂存，10 文件／500 行 | 0.592 / 0.592 | 0.623 / 0.621 | 0.580–0.760 |
| 未暂存，10 文件／500 行 | 1.166 / 1.168 | 1.213 / 1.197 | 1.150–1.365 |
| 暂存，100 文件／5000 行 | 1.756 / 1.757 | 1.787 / 1.787 | 1.737–1.935 |
| 未暂存，100 文件／5000 行 | 2.341 / 2.347 | 2.379 / 2.389 | 2.316–2.575 |

这些数字是输入到测试绘制的当前成本，不是原生帧率，也不是相同方法下的修改前后收益。旧 quick 对比未检出统计显著的性能收益（p > 0.05），且旧场景默认关闭换行、连续滚动会停留在钳制边界。现有基准已改为交替方向，并将预热区域跳转明确命名；其结果不能与旧方法直接比较。本次新增软换行探针没有同方法的修改前基线。

### 宽度变化后的重排

另一个探针固定每文件 128 行，交替宽度 160/240 共 9 次，分别测量前台返回与后台收敛。测试执行器强制走后台路径，因此前台数字不代表原生执行器实际等待 5/1 ms 同步预算的成本。

| 文件数 | 前台中位数／范围（ms） | 收敛中位数／范围（ms） |
| --- | --- | --- |
| 2 | 0.002 / 0.001–0.019 | 0.981 / 0.967–1.044 |
| 16 | 0.003 / 0.002–0.110 | 8.731 / 8.361–57.696 |
| 64 | 0.003 / 0.002–0.411 | 34.958 / 34.432–35.529 |

重排收敛时间不应加到已经收敛的纯滚动成本中；内容或配置变化后的中间态仍需在原生窗口检查跳动与跟手性。

## 内存与原生验收边界

高亮缓存的 10 MiB 预算包含 span 和估算的条目、链表开销；空结果与替换成本回归通过。这是缓存成本上限，不是进程 RSS。换行器归还 GPUI 池，池保留字体宽度缓存；取消和关闭测试验证文档、任务输入释放，不要求文本系统释放其有意缓存。

尚未测量进程 RSS、峰值分配、原生 GPU 帧时间与完整 DiffView 帧，也未通过原生窗口重现并确认用户报告的掉帧已消失。原生 release 验收应固定文件、字体和窗口宽度，检查持续滚动、瞬时大跳转、编辑后立即滚动、宽度变化与关闭重开，并用主线程采样和帧时间区分内容重排、字体塑形与呈现成本。

复现命令与场景说明见 [基准说明](../zcv-benchmarks/README.md)。
