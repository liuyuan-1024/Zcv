# zcv-search

搜索能力域：共享搜索会话、文档搜索工具项和项目搜索视图。

## 所有权与生命周期

- `SearchBar` 拥有查询与替换输入、匹配选项、可见性、弱搜索目标及目标事件订阅。匹配结果和活动匹配由目标自身拥有。
- 普通文档使用 Pane 的按需搜索会话；项目搜索、差异视图与提交图各自持有会话，切换标签不复制或转移查询状态。
- 工具栏通过 `SearchBarBinding` 切换当前呈现的会话；切换时解绑旧目标，隐藏或释放时调用 `clear` 结束绑定。该类型不持有目标强引用，不拥有查询、选项或目标事件订阅。
- 宿主负责解析搜索目标：项目搜索与提交图搜索自身，差异视图搜索内层 `Editor`。固定会话的普通文档工具栏直接更新 `SearchBar` 的目标，同样使用其订阅生命周期。
- 搜索栏的文件折叠插槽由 `SearchBarSlots::file_folding` 构造，只读取 `Editor` 的展开状态；点击交给编辑器统一切换当前文件集合，不另存文件列表或折叠状态。

## 边界

工作区只提供 `SearchableItem` 和工具栏协议，不依赖具体搜索能力。项目扫描和搜索结果装配属于项目搜索视图；文本匹配与编辑器内导航由对应搜索目标实现。
