# zom 文档规范

> 本文规定 `zom` workspace 内所有文档、代码注释与面向人的字符串字面量的分层、章节模板和写法。新增或修改文档前先读本文。

## 适用范围

本规范覆盖 workspace 内的全部 Markdown 文档、代码注释与面向人的字符串字面量。子 crate 不得放宽本文规则。

`zom-engine` 现有文档是本规范的事实模板；本文把它显式化、项目化。

## 文档分层

- `README.md` —— crate / 项目入口概览：这是什么、负责什么、不负责什么、依赖谁。**稳定**。
- `agents/global.md` —— 全局 agent 工作约定、测试命令、代码风格。**稳定**。
- `agents/project.md` —— workspace 项目结构、项目独有约束与统一测试策略。**稳定**。
- `<crate>/AGENTS.md` —— crate 独有 AI 协作规则 + 稳定工程约束。**稳定**。
- `<规范>.md` —— workspace 级规范，如本文。**稳定**。
- `docs/<规范>.md` —— crate 或能力域内的项目级规范。**稳定**。
- `docs/<能力>.md` —— crate 能力边界与长期架构方向。**稳定**。
- `docs/STATUS.md` —— 当前状态、结构快照、建议命令。**可变**。
- `TODO.md` —— 开发规划与阶段计划。**可变**。

**核心分界：稳定文档只写稳定规则与边界。阶段流水、逐文件账本、临时实现细节、「本次改动」一律不进稳定文档；确需记录时进 `STATUS.md` 或 `TODO.md`，且保持高层。**

## 章节模板

### crate README.md

```text
# crate 名
<一句话定位>

## 定位        负责什么 / 不负责什么 / 在分层中的位置 / 判据
## 核心能力    或「核心类型」，列关键类型与能力
## 依赖        依赖边；宿主 crate 必写，engine 可省
## 结构概览    src 布局
## 相关文档    相对路径链接
## 状态        骨架 / 成熟阶段说明
```

成熟 crate（如 `zom-engine`）可把 `## 结构概览` 写成 `## 目录概览`、`## 状态` 写成 `## 文档维护`。

### agents/*.md 与 AGENTS.md

workspace 层不再保留 `AGENTS.md` 入口壳。

全局规则写入 `agents/global.md`，项目独有规则写入 `agents/project.md`。AI 工具参与 workspace 前必须同时阅读这两个文件。

子 crate 的 `AGENTS.md` 以 `zom-engine/AGENTS.md` 为模板：必读上下文 / AI 工作身份 / 项目定位 / 阶段与范围 / 代码组织 / 编码风格 / 不变量 / 架构决策 / 验证要求 / 工作模式 / 回答风格 / 文档维护。

子 crate 的 `AGENTS.md` 只能收紧、不能放宽 workspace 层拆分文档。骨架阶段的宿主 crate 暂不单独配 `AGENTS.md`，由 `agents/global.md` 与 `agents/project.md` 统辖。

### docs/STATUS.md

总览 / 已收口能力 / 明确不做 / 当前结构 / 验证建议。是唯一记录「当前阶段状态」的文档。

## 写法风格

- **语言**：中文是第一语言（见 `agents/global.md`）。需要兼顾检索性时用「中文说明 + 英文术语」。
- **标点**：正文、**代码注释**、**面向人的字符串字面量**（如 `Display` 错误消息、`todo!` 占位消息）统一用全角中文标点（，。、：；（）「」）。Rust 标识符、类型名、路径、命令、协议名保持原样，放在反引号内。
- **语气**：稳定文档只陈述稳定事实与规则，不写流水账、不写「本次改动」、不写完成时间线。
- **链接**：跨文档引用用相对路径，如 `../agents/global.md`。
- **代码块**：结构图、目录树、签名示例用 ```text 或对应语言围栏。

## 变更 → 文档映射

```text
项目 / crate 概览               -> README.md
workspace 架构原则              -> 架构原则.md
全局 agent 规则                 -> agents/global.md
workspace 项目规则              -> agents/project.md
crate 独有 AI 协作规范          -> <crate>/AGENTS.md
crate 能力边界                  -> docs/<能力>.md
workspace 测试目录职责           -> agents/project.md
阶段状态、结构快照、建议命令    -> docs/STATUS.md
开发规划、阶段计划              -> TODO.md
文档规范本身                    -> 文档规范.md
```

## 文档维护

- 主文档只维护稳定规则与大方向。非原则性变化默认不改主文档。
- 文档、代码、用户要求冲突时，必须指出冲突，不擅自取舍。
- 文档修改通常只需审阅 diff。
