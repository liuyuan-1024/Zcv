# zcv-preview-markdown

`zcv-preview-markdown` 把 Markdown 源码投影为原生块元素预览（源码派生 `Source`、流式排版 `Flow`）。

公共入口是 [`src/preview_markdown.rs`](src/preview_markdown.rs)。

## 职责

- 解析源码 `MultiBuffer` 的 Markdown 文本并渲染为块/行内元素。
- 对代码围栏做语法高亮、对公式和 Mermaid 图表做后台渲染。
- 为每个块记录源码来源区间，为标题生成文档内锚点；点击 `#标题` 链接、从大纲跳转或源码/预览切换时，把 `MultiBufferAnchor` 解析为预览滚动位置。预览位置以锚点保存，不使用裸像素偏移。
- 链接跳转与文本选择共用同一套命中几何（SelectionLayout）：链接区间随渲染登记为可丢弃缓存，鼠标按下时先做链接精确命中（一次按下直接跳转，不落光标，也不依赖跨帧合成的 click 事件），未命中链接才落光标开始选择。
- Markdown 预览支持完整的鼠标选择：拖拽、双击选词、三击选块、Shift+点击扩展、全选与复制；拖拽越界时自动滚动跟随。复制结果是块树投影的纯文本（公式复制为 LaTeX 源码），不包含 Markdown 标记。
- 选区形状与 Editor 完全一致：圆角（行高 15%）、折行段落内的行阶梯过渡、跨行行尾延伸，由 zcv-ui 的共享形状原语（selection_shape）统一提供，两侧不会出现视觉分叉。
- 键盘扩展选区：Shift+方向键从活动端按字素（左右）或渲染行（上下）扩展，固定端在整个键盘序列中保持不变，反向移动越过固定端时选区反向；键位复用 editor 命名空间的 SelectLeft/Right/Up/Down。
- 预览显示选择光标：活动端的渲染投影（2px 竖线，与 Editor 的 bar 光标一致），有焦点、存在锚点且闪烁可见时绘制；单击落定显示在点击处，键盘扩展与拖拽跟随活动端，交互时暂停闪烁，失焦消失。
- 渲染预览内容；源码与预览切换由工作区的工具项承担。

## 所有权

- 视图持有解析后的块、代码高亮任务、公式与 Mermaid 图片缓存，不持有工具栏视图。
- 视图持有预览专属的选择、滚动和命中测试状态；这些状态不修改源码文档，也不进入其他预览类型。
- 选择状态锚定块树投影的稳定文本（SelectableText），跨帧、跨渲染与公式异步加载保持不变；渲染期只重建可丢弃的命中几何缓存（SelectionLayout），公式图片加载不改变选择坐标空间。光标闪烁状态机（BlinkManager）由 zcv-ui 提供，Editor 与预览共用。
- 命中测试覆盖块间隙与内容边界：点击空白按间隙中点归属相邻块，内容上下越界钳制到首末文本端点；公式占位区域按占位中心分界命中到公式源码边界。
- 阅读位置以 `MultiBufferAnchor` 保存；源码/预览标签切换只做一次锚点交接，不建立持续双向像素同步。
- 源码文档内容由源码 `MultiBuffer` 拥有，视图只读取快照。
- 代码围栏高亮使用的语言注册表来自源码 `MultiBuffer`。

## 不变量

- 源码 `MultiBuffer` 必须携带语言注册表；缺失即装配顺序错误，显式失败，不静默退化为无高亮。
- 源码与预览切换由 `zcv_workspace::PreviewToolbar` 作为 Pane 工具项统一承担，预览视图不持有也不返回工具栏视图。
- 渲染始终从窗口/工作区读取内容排版。
- 渲染注册的文本单元必须与选择投影的片段一一对应，顺序错配即装配错误，显式失败；空段落、空代码行与空单元格在投影与渲染两侧一致跳过。

## 验证

cargo check -p zcv-preview-markdown
