# zom-ai

`zom-ai` 是 zom 宿主层的 AI 抽象 crate，负责定义 AI 请求、提案、编辑范围与服务提供方接口。

## 定位

`zom-ai` 只放稳定的抽象边界：数据类型、服务提供方 trait，以及与编辑提案直接相关的错误类型。

它只依赖 `zom-engine`，并保持零网络依赖。具体模型服务、HTTP 客户端、鉴权、序列化等实现应放在上层宿主或独立的提供方 crate 中。

它不依赖 `zom-command`。AI 可以作为命令或编辑的来源，但命令词表解析应留在组合根完成，避免让 AI 抽象层反向认识命令系统。

## 核心类型

- `AiRequest`：一次 AI 请求，包含用户指令和上下文。
- `AiProposal`：AI 返回的编辑提案，包含摘要和编辑列表。
- `ProposedEdit`：单个编辑，包含目标范围和替换文本。
- `ProposedRange`：以字节区间表达的编辑范围。
- `AiProvider`：AI 服务提供方接口。
- `AiError`：请求失败或被拒绝时返回的错误。

## 依赖边界

```text
zom-ai → zom-engine
```

`zom-ai` 不直接接入网络，不持有 API key，也不依赖具体模型 SDK。

## 文件结构

```text
src/lib.rs    AI 请求、提案、编辑范围、服务提供方接口与错误类型
```

## 发布状态

0.2.0 版本保留当前最小 API 面，重点保证依赖边界清晰、文档与实现一致、对外描述不过度承诺尚未落地的能力。
