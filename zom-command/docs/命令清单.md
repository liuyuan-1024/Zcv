# 命令清单

当前 `zom-command::commands::*` 已注册的命令、`HostEffect` 已有的变体、以及待实现的命令 backlog。

**本文件随命令增删变动**，是滚动状态而非稳定规范。"为什么这样设计"看 [`命令与快捷键系统设计.md`](命令与快捷键系统设计.md)。

---

## 1. 已注册命令

### 1.1 `editor.*` —— 编辑

handler 直接操作 `CommandContext { workspace, views, queue }`，不 emit effect。

| 命令 id | 标题 | 默认键位 | 参数 |
|---|---|---|---|
| `editor.insert_text` | 插入文本 | — （走 IME） | `text: String` |
| `editor.replace_selection` | 替换选区 | — | `text: String` |
| `editor.insert_newline` | 换行 | `enter` / `return` | — |
| `editor.indent` | 缩进 | `tab` | — |
| `editor.outdent` | 反缩进 | `shift-tab` | — |
| `editor.delete_backward` | 向后删除 | `backspace` | — |
| `editor.delete_forward` | 向前删除 | `delete` | — |
| `editor.select_all` | 全选 | `mod-a` | — |
| `editor.undo` | 撤销 | `mod-z` | — |
| `editor.redo` | 重做 | `mod-shift-z` | — |
| `editor.move_selection` | 移动选区 | 见下表 | `direction / unit / extend` |
| `editor.ime_commit` | 提交输入法组合 | — | `text: String` |
| `editor.ime_cancel` | 取消输入法组合 | `escape` | — |

**`editor.move_selection` 的键位变体**（同一条命令，按 args 区分）：

| chord | direction | unit | extend |
|---|---|---|---|
| `left` | Previous | Grapheme | false |
| `right` | Next | Grapheme | false |
| `shift-left` | Previous | Grapheme | true |
| `shift-right` | Next | Grapheme | true |
| `alt-left` | Previous | Word | false |
| `alt-right` | Next | Word | false |
| `alt-shift-left` | Previous | Word | true |
| `alt-shift-right` | Next | Word | true |
| `home` | Previous | Line | false |
| `end` | Next | Line | false |
| `shift-home` | Previous | Line | true |
| `shift-end` | Next | Line | true |
| `pageup` | Previous | Page | false |
| `pagedown` | Next | Page | false |
| `shift-pageup` | Previous | Page | true |
| `shift-pagedown` | Next | Page | true |

### 1.2 `editor.save` —— 文件保存

| 命令 id | 标题 | 默认键位 |
|---|---|---|
| `editor.save` | 保存 | `mod-s` |

handler 调 `Workspace::save_file(buffer_id)`，文件 IO 在 zom-workspace 内部完成。

### 1.3 `app.*` / `window.*` —— 窗口控制

handler emit `HostEffect`，由宿主翻译到 GPUI Window API。

| 命令 id | 标题 | 默认键位 | emit |
|---|---|---|---|
| `app.quit` | 退出应用 | `mod-q` | `HostEffect::Quit` |
| `window.minimize` | 最小化窗口 | `mod-m` | `HostEffect::Minimize` |
| `window.toggle_maximize` | 切换窗口最大化 | `mod-shift-m` | `HostEffect::ToggleMaximize` |

### 1.4 `panel.toggle.*` —— Dock 面板切换

handler emit `HostEffect::TogglePanel(panel_str_id)`，宿主用 `PanelId::from_command_str_id` 解析回枚举。

| 命令 id | panel 字符串 id | 标题 | 默认键位 |
|---|---|---|---|
| `panel.toggle.file_tree` | `file_tree` | 切换面板：文件树 | `mod-shift-e` |
| `panel.toggle.version_control` | `version_control` | 切换面板：版本管理 | `mod-shift-g` |
| `panel.toggle.outline` | `outline` | 切换面板：大纲 | `mod-shift-o` |
| `panel.toggle.project_search` | `project_search` | 切换面板：项目搜索 | `mod-shift-f` |
| `panel.toggle.terminal` | `terminal` | 切换面板：终端 | `mod-j` |
| `panel.toggle.debug` | `debug` | 切换面板：调试 | `mod-shift-d` |
| `panel.toggle.keyboard_shortcuts` | `keyboard_shortcuts` | 切换面板：快捷键 | `mod-shift-k` |

## 2. `HostEffect` 变体

闭合枚举，详见 [`zom-command/src/effects.rs`](../src/effects.rs)。

| 变体 | 触发命令 | 宿主翻译 |
|---|---|---|
| `Quit` | `app.quit` | `cx.quit()` |
| `Minimize` | `window.minimize` | `window.minimize_window()` |
| `ToggleMaximize` | `window.toggle_maximize` | `window.zoom_window()` |
| `TogglePanel(String)` | `panel.toggle.*` | `App::toggle_panel(PanelId)` |

## 4. backlog

按域 / 优先级排：

### 文本编辑（engine 已就绪）

- `editor.move_selection` 扩展更多 `MovementUnit`：`identifier` / `subword` / `symbol`
- 真实视口页移动：当前 `Page` 先按固定逻辑行步长移动，后续接入 view 可见行数。
- 剪贴板：`editor.copy / cut / paste` —— 需新 `HostEffect` 走 OS 剪贴板

### 文件 / 工作区

- `file.open` / `file.open_recent` / `file.new`
- `workspace.show_picker` / `workspace.add_folder`
- `editor.save_as`

### 命令面板 / 菜单

- `commands.show_palette` —— 需新 `HostEffect::ShowCommandPalette`

### Panel / Dock 操作

- 调整 dock 宽度 / 高度（拖动也可以走命令）
- panel 内部 split / tab group（手册 19 章）

### 搜索 / 替换（engine 已就绪）

- `search.find_in_buffer` / `search.find_next` / `search.replace`
- `search.find_in_project` —— 需要 project search 后端

### LSP / 诊断（待 LSP 子系统）

- `diagnostics.show_problems` / `diagnostics.open_lsp_status`
- `lsp.goto_definition` / `lsp.find_references` / `lsp.rename`

### AI

- `ai.chat.send` / `ai.propose_edit` / `ai.accept_proposal`
