# zcv-project-tree

`zcv-project-tree` 实现项目文件树面板 `ProjectTreePanel`：行渲染、选择、拖拽移动、行内重命名与文件操作动作转发。

公共入口是 [`src/project_tree.rs`](src/project_tree.rs)。模块按职责拆分：`render`（行渲染）、`drag`（拖拽）、`editing`（行内编辑）、`transfer`（文件移动/复制）、`execute`（动作执行）、`actions`（命令）。

## 职责

- 订阅 `Project` 的条目快照变化并刷新可见行。
- 把树行渲染为 `zcv-ui` 的通用树行几何。
- 把用户操作转换为项目文件操作并处理错误反馈。

## 所有权

- 面板拥有自身的选中、展开、编辑与拖拽状态。
- 持久目录展开意图由树状态保存；树内拖拽会话独占载荷、悬停计时器和临时展开目录。可见行从两者的并集派生，会话结束即撤销临时展开。
- 普通点击在确认未拖拽后收拢为被点击行的单选，并按该行身份执行打开或展开；键盘激活使用当前游标行。按下已选中行时暂时保留多选，以便拖拽整组选中项。
- 文件系统条目快照与 Git 状态事实由 `zcv_project::Project` 拥有，面板只提交展开需求并做派生投影。
- 新建占位行由面板的编辑态派生，渲染与滚动都从显示行投影定位；目录展开异步重建后按新行位置完成可见性定位。

## 不变量

- 树行行高/缩进来自 `zcv-ui::TreeRowFrame`，按窗口 `rem_size` 计算，保证行与命中测试一致。
- 列表按内容自适应高度（Infer），行数不足时行下方空白区域承载「视为项目根目录」的交互：左键点击清空选中、右键以根部署菜单、拖放以根为落点。
- 选中可停留为空（无渲染期兜底）：键盘导航从空选中恢复首/末行，新建与粘贴回退到项目根。
- 面板不复制项目文件状态；Worktree 在后台核对受文件事件影响的已加载目录，面板只在快照更新后重建行。
- 内部复制／剪切语义由面板持有；系统剪贴板的文件路径与外部拖放进入同一条外部复制流程。目标目录、冲突确认和进度由面板处理，文件复制由 `Project` 执行。
- 拖拽多选载荷按可见行序从选中集派生；行模型替换或选中集变化时重建，普通绘制不扫描全部行。
- 树内拖拽放到载荷中的任一行时取消整次移动；落点高亮、悬停展开与实际执行使用同一落点解析。拖拽与传输层不修改目录展开意图，粘贴动作主动展开目标以展示结果。
- 内部条目与外部文件拖拽共用面板边缘滚动任务；边缘区按面板高度计算，靠近边缘时加速。指针移动只更新速度，离开边缘、退出文件拖拽或放下时停止。
- 测试位于 `src/test/`，通过面板公开行为验证。

## 操作流程

选择状态只由 `TreeState` 持有。复制、剪切、删除与拖拽从同一份选择事实派生源条目，并用同一规则排除项目根与互为祖先的重复项。树内拖拽在开始时冻结载荷；目标解析先净化源条目，再为高亮、悬停展开和放下产生相同的有效落点。

粘贴、树内拖拽和外部拖放各自确定输入来源与目标目录，随后提交 `TransferRequest`。传输规则将其整理为 `TransferPlan` 并组合目标路径；冲突会话完整持有本次操作的冲突项、非冲突项和发起来源。拖拽落点预先拒绝不可移动的目标，主动粘贴的文件错误由 `Project` 报告。完成后按发起来源呈现结果。

| 操作入口 | 目录展开 | 完成后的选择 | 剪贴板 |
| --- | --- | --- | --- |
| 普通点击或键盘展开 | 修改持久展开意图 | 由选择状态决定 | 不变 |
| 树内拖拽 | 悬停时仅临时展开，结束即撤销 | 选中仍可见的移动结果或目标目录 | 不变 |
| 粘贴 | 主动展开目标目录 | 选中首个成功结果 | 剪切移动成功后改为复制 |
| 外部拖放 | 保留持久展开意图 | 保留当前选择 | 不变 |

取消拖拽不提交文件操作，也不修改持久展开意图。传输执行层不读取当前鼠标位置或多选集合。
